# Todo Cloud

A modern full-stack task management application built to explore software engineering, cloud infrastructure, and modern backend development.

The goal of this project is not only to build a Todo application, but to understand how a production-ready web application is designed, developed, containerized, and deployed to AWS.

---

## Project Goals

- Build a modern full-stack application
- Learn backend development with FastAPI
- Work with PostgreSQL
- Containerize the application using Docker
- Configure Nginx as a reverse proxy
- Deploy the application to AWS EC2
- Follow software engineering best practices
