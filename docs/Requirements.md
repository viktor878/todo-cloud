# Requirements

## Functional Requirements

- User can register.
- User can log in.
- User authentication is performed using JWT.
- User can create tasks.
- User can view their own tasks.
- User can edit their own tasks.
- User can delete their own tasks.
- User can mark tasks as completed.
- User can filter tasks by status.

## Non-functional Requirements

- HTTPS communication.
- JWT-based authentication.
- Dockerized application.
- PostgreSQL database.
- REST API.
- GitHub repository.
- AWS deployment.
- CI/CD with GitHub Actions.
- Responsive web interface.
